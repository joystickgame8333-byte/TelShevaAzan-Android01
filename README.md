# TelShevaAzan Android

Current app version: `0.6.58 (149)`

تطبيق Android عربي لتل السبع/النقب، مبني Native Java، ومجهز ليقترب من نسخة iPhone الحالية:

- مواقيت الصلاة لشهر مايو 2026
- الصلاة القادمة والعداد التنازلي
- أوقات الإقامة: الفجر 25، الظهر 15، العصر 17، المغرب 8، العشاء 15 دقيقة
- واجهة عربية RTL بثيمات نهارية/ليلية وصور المسجد النبوي
- صفحة التنبيهات واختيار صوت الأذان والصلوات المفعلة
- أذكار ونفحات خفيفة
- قبلة تل السبع بالبوصلة
- راديو القرآن الكريم من نابلس
- ويدجت الصلاة القادمة
- خمس ويدجت دائرية صغيرة: الفجر، المتبقي، مدة الإقامة، وقت الإقامة، الشروق
- أزرار اليوم السابق / اليوم / اليوم التالي
- المنطق: توقيت المسجد الأقصى الدهري + دقيقتين لتل السبع/بئر السبع + التوقيت الصيفي

## بناء APK بدون Android Studio

GitHub Actions يعمل تلقائيًا عند الرفع على فرع `main`، ويمكن تشغيله يدويًا أيضًا:

```text
Actions > Build Android APK > Run workflow
```

بعد نجاح البناء نزّل artifact:

```text
TelShevaAzan-debug-apk
```

افتحه وستجد:

```text
app-debug.apk
```

انسخ الملف لهاتف Android وثبته.
